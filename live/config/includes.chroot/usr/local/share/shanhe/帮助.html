山河 Linux 0.3.0 · 使用手册

山河 Linux 是一台「中文原生编程」操作系统：内置 卅语（sahou） 解释器与「卅语工作室」编辑器，界面参照 Windows 11，可运行大多数 Windows 软件与游戏。

一、写你的第一行中文代码

  1. 桌面双击 卅语工作室（或开始菜单 → 开发）。
  2. 新文件自带示例，直接按 F5 运行。
  3. 终端里也可以：sahou run 程序.saho；敲 卅 回车进入交互环境。
  4. 零基础？开始菜单 →「卅语课堂」，10 节闯关课边玩边学。
# 卅语速览（中英文关键字可混写）
年龄 = 输入("你多大了？")
如果 数(年龄) >= 18
    打印("欢迎来到成人世界。")
否则
    打印("你还是个孩子。")
完毕

二、键盘与输入法

  • 中文输入：Ctrl + 空格 切换 Fcitx5 拼音。
  • 编辑器快捷键：F5 运行 · Ctrl+S 保存 · Ctrl+F 查找替换 · Ctrl+G 跳转到行 · Ctrl+/ 注释 · Tab 缩进 · Ctrl+= / Ctrl+- 缩放字号 · Ctrl+N 新建。
  • 工作室 v2 新增：工具 → 卅语速查（关键字 / 函数 / 常见报错，双击即插入）、 片段菜单（14 个代码片段）、工具 → 语法检查（改错提示）、 文件 → 打包为独立程序（把程序编译成单文件可执行程序）。
  • 工作室 v2.1 新增：输入时关键字自动补全；输入括号自动配对、 块开头回车自动补「完毕」；文件 → 最近打开； 工具 → 在浏览器中预览（网页）（转译 + 本地服务 + 开浏览器）； 工具 → 记号流 / 语法树 / 卅语版本（诊断面板）； 工具 → 库包列表（stones 自带库包一键安装）。

三、运行 Windows 软件

  • 双击 .exe 即可安装/运行（Wine 已内置）。
  • 遇到中文乱码 → 「Wine 助手」→ 中文字体修复。
  • 部分依赖 Windows 内核驱动的软件（反作弊网游、部分杀毒）无法运行，详见兼容性文档。

四、显卡

  • VMware 虚拟机：开启 3D 加速即可（虚拟机设置 → 显示器 → 加速 3D 图形）。
  • 物理机 NVIDIA：开始菜单 → 「安装 NVIDIA 驱动」，装完重启，nvidia-smi 验证。

五、常用位置

内容位置
卅语示例程序~/示例、/usr/local/share/sahou/示例
卅语全套文档/usr/local/share/sahou/文档
我的程序~/我的程序
Wine 容器（C 盘）~/.wine/drive_c

提示：体验模式（Live）里的所有改动重启后丢失。要长期使用， 用 GRUB 菜单的「安装 山河Linux」装到虚拟硬盘。
