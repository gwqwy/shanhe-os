# VMware 安装指南 —— 山河 Linux

> 目标：5 分钟内在 VMware 里把山河Linux 跑起来。

## 一、虚拟机配置建议

| 项目 | 推荐值 | 说明 |
|---|---|---|
| 虚拟机类型 | Debian 12.x 64 位（或 Linux 5.x 64 位内核） | VMware 内置模板即可 |
| 内存 | **4096 MB 起**（跑 Windows 软件建议 8192 MB） | KDE + Wine 比较吃内存；系统已配 zram 压缩交换 |
| 处理器 | 2 核起 | 编译卅语时多核更快 |
| 硬盘 | 30 GB 起（NVMe/SCSI 均可） | 要安装 Windows 大软件就给 60 GB |
| CD/DVD | 挂载 `山河Linux-0.3.0-amd64.iso` | 启动时勾选"启动时连接" |
| 显示器 | **勾选「加速 3D 图形」**，图形内存 4 GB | 3D 加速决定桌面流畅度 |
| 网络 | NAT | 默认即可 |
| 固件 | BIOS 或 UEFI 均可 | ISO 双模式引导 |

### 手工 .vmx 模板
本目录提供 [`山河Linux-0.3.0.vmx`](山河Linux-0.3.0.vmx)：用 VMware 打开前先在该文件里
把 `ide1:0.fileName` 改成你的 ISO 实际路径（或直接在 VMware 里重新指定 CD/DVD）。

## 二、启动与体验

1. 开机 → GRUB 中文菜单：
   - **启动 山河Linux（体验模式）**：不装盘直接用，关机后改动丢失；
   - **安装 山河Linux**：装到虚拟硬盘（推荐，装完功能与体验版完全一致）。
2. 体验模式自动登录用户 `user`；首次进入桌面会自动应用 Win11 布局（任务栏居中、山河蓝配色）。
3. 双击桌面「**卅语工作室**」→ 按 F5 运行示例程序。

## 三、安装到虚拟硬盘（可选但推荐）

GRUB 选安装项 → 文本安装器 → 装完重启拔掉 ISO。
安装的系统与 Live 版完全相同（live-installer 整盘复制），卅语、编辑器、Wine、
输入法全部预装。

## 四、VMware Tools

系统已内置 **open-vm-tools**（开源版 VMware Tools）：自适应分辨率、剪贴板共享、
文件拖放开箱即用，无需手动安装。

## 五、常见问题

| 现象 | 处理 |
|---|---|
| 开机黑屏/花屏 | 虚拟机设置 → 显示器 → 关闭"加速 3D 图形"再试（系统会回退到软件渲染） |
| 分辨率太小 | 已装 open-vm-tools，最大化窗口即自适应；或 设置 → 显示器 手动调 |
| 鼠标不同步 | 一般自动装好 tools；仍异常则在虚拟机设置 → USB 兼容性选 3.1 |
| 中文输入法 | Ctrl+空格 切换 Fcitx5 拼音 |
| 宿主机⇆虚拟机复制粘贴 | 确认会话为 X11（默认已锁定），且 选项 → 客户机隔离 勾选复制粘贴 |
| 想跑 3D 游戏 | VMware 虚拟显卡性能有限，重度 3D 请用物理机 NVIDIA 驱动或 GPU 直通（见 docs/NVIDIA显卡指南.md） |
