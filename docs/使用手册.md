# 山河 Linux · 使用手册

> 同内容内置于系统（开始菜单 → 山河帮助）。本篇为完整版。

## 1. 首次开机

- GRUB 中文菜单：**启动 山河Linux（体验模式）** 或 **安装 山河Linux**。
- 体验模式自动登录用户 `user`；首次进入桌面自动应用 Windows 11 风格布局
  （底部居中悬浮任务栏、山河蓝配色、山河绽放壁纸）。
- 要长期使用请用「安装」项装盘（装完与体验版完全一致，所有预装都在）。

## 2. 中文编程：卅语

### 2.1 三种打开方式

| 方式 | 操作 |
|---|---|
| 图形 IDE | 桌面双击 **卅语工作室**：语法高亮、F5 一键运行、内置示例库、REPL 面板 |
| 交互环境 | 开始菜单 → 卅语交互终端；或终端敲 `卅`（等于 `sahou`），一行一执行 |
| 命令行 | `sahou run 我的程序.saho` |

### 2.2 语言一分钟

```saho
# 卅语：中英文关键字可混写，字符串支持 {表达式} 插值
名字 = "山河"
打印("你好，{名字}！")

函数 阶乘(n)
    结果 = 1
    遍历 i 于 从a到b(1, n + 1)
        结果 = 结果 * i
    完毕
    返回 结果
完毕

打印(阶乘(10))          # 3628800
```

- 关键字：如果/if · 否则/else · 当/while · 遍历/for · 函数/fn · 返回/return …
- 标准库：`用 "算术库"`、`用 "文本库"`、`用 "数据库"`、`用 "应用"`（桌面/手机应用）……
- 全套中文教程在 `/usr/local/share/sahou/文档`，示例在 `~/示例`。

### 2.3 编辑器快捷键

| 键 | 功能 |
|---|---|
| F5 | 保存并运行 |
| Ctrl+S | 保存 |
| Ctrl+F | 查找 |
| Ctrl+N / Ctrl+O | 新建 / 打开 |
| Ctrl+W | 关闭标签 |

## 3. 中文输入

`Ctrl + 空格` 切换 Fcitx5 拼音；托盘图标可切换全角/标点/简繁。

## 4. 运行 Windows 软件

1. **双击 .exe** 即可（文件管理器已关联 Wine）。
2. 图形化入口：开始菜单 → **Wine 助手**：运行程序 / winecfg 配置 / 程序卸载 /
   中文字体修复 / 重建容器。
3. 中文乱码 → Wine 助手 →「中文字体修复」（或终端 `winetricks cjkfonts`，需联网）。
4. 命令行方式：`wine 程序.exe`；卸载 `wine uninstaller`；配置 `winecfg`。
5. 哪些能跑哪些不能 → 见《Windows软件兼容说明.md》。

## 5. 显卡

- **VMware**：虚拟机设置勾选「加速 3D 图形」即可，无需装驱动。
- **物理机 NVIDIA**：开始菜单 → **安装 NVIDIA 驱动** → 输密码等装完 → 重启 →
  终端 `nvidia-smi` 验证。详见《NVIDIA显卡指南.md》。

## 6. 系统维护

| 操作 | 命令 |
|---|---|
| 更新系统 | `sudo apt update && sudo apt full-upgrade` |
| 装新软件 | `sudo apt install 软件名` 或 KDE 软件中心 |
| 查看系统信息 | 终端 `fastfetch` |
| 磁盘占用 | `dolphin` → 状态栏，或 `ncdu` |

## 7. 常见问题

| 现象 | 处理 |
|---|---|
| 任务栏不见了 | 终端 `plasmashell --replace`；重新应用布局：删除 `~/.config/山河布局已应用` 后注销重登 |
| 中文显示方块 | 系统自带 Noto CJK；个别 Wine 程序用 Wine 助手修字体 |
| F5 没反应 | 程序有语法错误时输出区会显示中文报错；按提示改 |
| Windows 软件启动崩溃 | `winecfg` 里把 Windows 版本调到 Win10；仍不行查兼容性文档 |
| 想恢复默认布局 | 删掉 `~/.config/山河布局已应用`，注销重新登录 |
