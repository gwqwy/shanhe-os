# 山河 Linux · 架构设计

## 1. 设计目标

1. **中文原生编程**：中文不仅是界面语言，更是第一编程语言。
2. **开箱即写**：开机即有解释器 + 编辑器 + 示例，零安装。
3. **Windows 观感**：界面布局、配色、操作习惯参照 Windows 11。
4. **Windows 生态**：可运行大多数 Windows 软件与游戏（Wine 兼容层）。
5. **VMware 优先**：一切默认配置保证虚拟机内开箱可引导、可图形加速。

## 3. 关键决策与理由

### 3.1 为何基于 Debian 13 + live-build，而不是从零造内核
- 「以 Linux 为基础」：Linux 内核 + GNU 用户态即构成完整基础；内核并非必须自行编写。
- Debian 提供数十万经过安全维护的包与稳定内核，这是任何"能跑 Windows 软件"的
  系统的现实前提（Wine、Mesa、Plasma 都是重量级生态件）。
- live-build 是 Debian 官方定制发行版工具：声明式配置 + 钩子注入，产物为
  标准 iso-hybrid，VMware/物理机/U 盘通吃。
- 保留 `build-kernel.sh`：需要跟进上游内核特性（新硬件、调度器）时可一键
  直编 torvalds/linux 主线。

### 3.2 为何 KDE Plasma 做 Windows 风格
- Plasma 是 Linux 上可定制性最强的桌面：任务栏（icons-only taskbar）、开始菜单
  （kickoff）、系统托盘全部组件化，可用官方脚本 API（evaluateScript）重排为
  Win11 布局——底部悬浮、居中、48px 高。
- 相比 GNOME（固定工作流）或轻量 WM（需要从零拼装），Plasma 是"像 Windows"成本
  最低、稳定性最高的方案。

### 3.3 卅语如何"内置"进系统
- 构建 ISO 时，钩子 `0010-build-sahou` 在 chroot 内执行：
  1. `GOOS=js GOARCH=wasm go build` 先产出浏览器 WASM 运行时；
  2. `go build` 产出原生解释器，**把标准库与 WASM 一并嵌入单文件**；
  3. 安装到 `/usr/local/bin/sahou`，软链中文命令 `卅`；
  4. 注册 MIME `text/x-saho`、安装示例到 `~/示例` 与系统示例库。
- 源码快照随 ISO 保留在 `/usr/local/src/sahou`，系统内可自行重编或改造。
- 编辑器侧：GtkSourceView 语法文件 `sahou.lang` 与上游 `lexer.go` 关键字表
  逐项对齐（23 对双语关键字、30 个内置函数、10 个纯卅标准库包）。

### 3.4 Windows 软件兼容：Wine 的能力边界
- Wine 在用户态把 Win32 API 转译为 POSIX/OpenGL 调用，不运行 Windows 内核，
  因此**没有 100% 兼容**这回事。
- 策略：日常软件（办公、工具、老游戏、大部分单机游戏）目标可跑；
  依赖 Windows 内核驱动的软件（反作弊网游、部分杀软、驱动安装器）明确标注
  不可用，详见《Windows软件兼容说明.md》。

### 3.5 显卡策略（VMware 与物理机双轨）
- **VMware**：使用 VMware 虚拟显卡（SVGA II）+ Mesa 3D + open-vm-tools。
  这是虚拟机里"用上显卡"的正确方式；NVIDIA 原生驱动在虚拟机中不适用
  （除非 GPU 直通）。
- **物理机**：一键脚本 `nvidia-install.sh`（nvidia-detect 选型 → 安装
  non-free 官方驱动 → initramfs 更新），桌面有对应入口，装完 `nvidia-smi` 验证。
- **游戏加速路径**：物理 NVIDIA + Vulkan + DXVK（Wine 内把 D3D9/10/11 转
  Vulkan），这是 Linux 上跑 Windows 3D 游戏的事实标准（Steam Proton 同款技术）。

## 4. 构建流水线

```
build.sh
 ├─ 依赖安装        live-build / rsync / xorriso / squashfs-tools
 ├─ 源码布置         vendor/sahou → includes.chroot/usr/local/src/sahou
 ├─ lb config       trixie · amd64 · iso-hybrid · 中文 locale/时区 · d-i live
 ├─ chroot 钩子
 │   0010 编译卅语（wasm → 原生二进制 → MIME/示例/中文命令）
 │   0020 工作室权限/MIME 关联
 │   0030 主题落地（locale-gen、kdeglobals、konsole、壁纸转 PNG、输入法）
 │   0040 Wine 中文字体表 + 容器自举脚本
 │   0050 系统标识/motd/瘦身
 ├─ binary 钩子
 │   9000 GRUB 菜单中文化
 └─ lb build        → shanhe-amd64.hybrid.iso → 山河Linux-0.2.0-amd64.iso
```

## 5. 首次启动流程

```
GRUB（中文菜单）
 └→ live 内核启动（zh_CN.UTF-8 / cn 键盘 / Asia/Shanghai）
     └→ SDDM → 自动登录 user
         ├→ autostart: 10-init-wine.sh    静默建 ~/.wine
         ├→ autostart: 11-wine-cjk.sh     导入中文字体注册表
         ├→ autostart: 00-shanhe-layout.sh 应用 Win11 布局 + 山河蓝（仅一次）
         └→ 桌面就绪：卅语工作室 / 示例 / 帮助 三图标
```
